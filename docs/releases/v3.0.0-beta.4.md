В этой бете на роутерах с Mihomo можно задать отдельный маршрут для каждого сервиса. Например, закрепить сервер за Claude, поручить YouTube выбор из пула Нидерландов и оставить Steam напрямую. [Инструкция со скриншотами](https://github.com/Sgadmer/xkeen-panel/blob/v3.0.0-beta.4/README.md)

### Что изменилось

- **Серверы.** Добавляйте несколько подписок и собирайте пулы из стран, отдельных серверов или целых подписок. В общем пуле по умолчанию до 8 серверов. Лимит меняется в разделе «Серверы → Автовыбор». Для исключения стран используется локация из подписки с учётом ручной правки.
- **Сервисы.** Карточки показывают подписку и текущую локацию. Порядок карточек можно менять. Защита при обрыве VPN включена по умолчанию, а для каждого сервиса можно задать своё правило. [Как работает защита](https://github.com/Sgadmer/xkeen-panel/blob/v3.0.0-beta.4/docs/selective-guard.md)
- **Re:filter.** В режиме «VPN по списку блокировок» адреса из базы идут через основной VPN, остальные — напрямую. Сохраняется возможность задать сервису свой маршрут или добавить исключение.
- **Диагностика и устройства.** Появились графики нагрузки и трафика, температура при наличии датчика и фильтр соединений по устройству и сервису. Устройства можно переименовывать в панели.
- **Вход и уведомления.** Домашний HTTPS можно настроить из панели для входа по Face ID на iPhone. Появились уведомления о смене сервера, состоянии VPN и новых версиях.

### Как установить

Для первой установки скачайте [навык для локального агента](https://github.com/Sgadmer/xkeen-panel/releases/download/v3.0.0-beta.4/xkeen-router-install.zip) или откройте [руководство](https://github.com/Sgadmer/xkeen-panel/blob/v3.0.0-beta.4/docs/installation.md). Если уже используете предварительную сборку этого форка, проверьте обновление в разделе «Настройки → Обновление панели».

Готовые файлы панели — `xkeen-panel-aarch64` для ARM64 и `xkeen-panel-mipsel` для MIPS little-endian. Файл `SHA256SUMS` содержит контрольные суммы обеих сборок и двух архивов.
