В этой бете исправлена прокрутка стран и добавлена проверка пинга отдельных серверов и групп.

- **Страны.** Длинный список на экране «Все серверы» помещается в доступную ширину. Его можно прокрутить кнопками по краям, полосой прокрутки или свайпом на телефоне.
- **Проверка сервера.** Нажмите значок обновления рядом с нужным сервером. Проверить можно и сервер, который сейчас используется.
- **Проверка группы.** Кнопка в заголовке страны проверяет все её серверы. Отдельные кнопки есть у автопула и готовых режимов провайдера.
- **Ход проверки.** Значки крутятся только у проверяемых серверов и сменяются результатом по мере готовности. Проверка продолжается после перехода в другой раздел. До её завершения повторный запуск заблокирован.

Значение в миллисекундах показывает время тестового HTTPS-соединения через VPN с самого роутера.

Обновление доступно в **Настройки → Обновление панели**. Для первой установки скачайте архив навыка или откройте руководство.
