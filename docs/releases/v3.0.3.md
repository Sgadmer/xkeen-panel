# v3.0.3

Один пинг, который меряет сам роутер, автовыбор без лишних переключений, понятные экраны серверов и журнала.

## Один пинг

- **Меряет только роутер.** Задержку всех серверов измеряет одна и та же проверка ядра Xray на роутере — та же, по которой роутер выбирает сервер. Своей отдельной проверки у панели больше нет, поэтому числа на главной, в автовыборе, во всех серверах и в режимах провайдера одинаковые.
- **Число не прыгает.** У сервера показан средний из трёх его последних замеров: один медленный или случайно быстрый ответ число не сдвигает. Подсказка у времени проверки показывает сами замеры, каждый своим цветом.
- **Роутер выбирает по этому же числу.** В каждом пуле трафик идёт через сервер с лучшим числом. Сервер, последний замер которого не получил ответа, не выбирается.
- **«Проверить пинг»** проверяет все серверы разом той же проверкой: 135 серверов — меньше чем за минуту. Затем через ответившие серверы загружается начало страницы; сервер, который отвечает, но страницы не загружает, отмечен и не попадает в автовыбор. На роутере с небольшим запасом памяти проверка идёт частями.

## Автовыбор и пулы

- **Замена без обрывов.** Сервер пула «Все локации», который дважды подряд не ответил роутеру, панель за 15 секунд заменяет следующим по скорости на 30 минут. Замену она сначала проверяет. Открытые соединения при этом не рвутся.
- **Режимы провайдера в пулах.** Режим провайдера, прошедший проверку роутера, участвует в автовыборе наравне с серверами. Прямые выходы внутри режима заблокированы, весь его трафик идёт через VPN.
- **Больше режимов провайдера.** Поддерживаются режимы, где одна группа серверов при отказе передаёт трафик другой группе.
- **Сигнал «VPN не отвечает»** для общего маршрута и карточек появляется только после двух неудачных проверок подряд.

## Экран «Серверы»

- **Компактные карточки.** У сервера одна строка с названием и значками: протокол, «в автовыборе», «локация исключена», «выбран». Ниже — подписка и заметка провайдера, справа — число и время проверки. Выбранный сервер обведён.
- **Исключенные локации** — плитка на экране серверов. Первыми в списке стоят «Режимы провайдера» и «Без страны».
- Во время проверки вместо числа видна серая полоска, на кнопке — полоски сигнала, по кнопке «Проверить пинг» бегут полосы.

## Остальные экраны

- **Главная.** Повторяющиеся события свёрнуты в одну строку с отметкой «×N», сегодняшние события идут без даты, число задержки окрашено.
- **Сервисы.** «Маршрут сохранён» появляется в самой карточке. Для сервера без страны написано его имя.
- **Журнал.** В «Недавних» видны имена сайтов, а не только IP-адреса. Соединения через пул помечены «VPN» и показывают сервер пула. Список устройств разделён на «В сети» и «Не в сети».
- **Устройства** — одна общая иконка: роутер не сообщает тип устройства.
- **Вход и безопасность.** Видны все ключи доступа; ключ можно добавить с другого устройства и удалить каждый по отдельности.
- **Исключения.** «Вернуть» восстанавливает выключенное исключение выключенным.
- **Уведомления.** «Смена сервера» не приходит, когда автовыбор сам переходит на лучший сервер пула.
- Боковое меню идёт в том же порядке, что нижняя панель телефона.

## Что важно знать

- Обновление сохраняет маршруты, пулы, исключения, списки XKeen и настройки защиты. После обновления ядра пулов один раз перезапускаются с новым каналом управления; открытые соединения при этом не рвутся.
- Всё перечисленное проверено на рабочем роутере с пятью подписками и автоматическими тестами.

Обновление доступно в **Настройки → О панели и обновление**.
