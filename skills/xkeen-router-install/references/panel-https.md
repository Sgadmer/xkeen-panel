# Домашний HTTPS и Face ID на работающей панели

HTTPS для Face ID включают по желанию владельца. Если его устраивает вход с паролем и одноразовым кодом по текущему адресу в домашней сети, сообщите, что этот шаг можно пропустить. Все изменения в этом сценарии выполняйте через кастомную панель XKeen.

1. Откройте панель в браузере в домашней сети. Если требуется вход, владелец вводит пароль и код непосредственно в окне входа. Перейдите в **Настройки → Вход и безопасность → Адрес панели и QR-код → Face ID на iPhone**. При статусе **«HTTPS-адрес готов»** перейдите к проверке ссылки в шаге 4. Если панель сообщает, что домен уже задан вручную, используйте его, уточнив адрес у владельца. Если мастер недоступен, сообщите, что показывает установленная сборка.
2. Нажмите **«Подготовить адрес для iPhone»**, оставьте предложенное неперсональное имя и нажмите **«Проверить адрес и параметры»**. Покажите владельцу полный адрес из предварительного просмотра, включая порт. Роутер использует имеющееся имя или регистрирует новое в CrazeDNS. Имя может быть видно в DNS и публичных журналах сертификатов. Доступ к самой панели мастер ограничивает домашней сетью.
3. Если показана галочка отключения доступа из интернета к штатному веб-интерфейсу, объясните, что она закроет и этот способ удалённого управления. Если владелец хочет сохранить его, завершите предварительный просмотр кнопкой **«Отмена»**. Получив подтверждение конкретного плана, отметьте согласованную галочку, если она есть, и нажмите **«Подтвердить настройку HTTPS»**. Роутер сам запросит и будет продлевать сертификат.
4. Дождитесь **«HTTPS-адрес готов»**. Пока идёт выпуск сертификата, панель обновляет статус каждые 10 секунд. Если требуется повтор, нажмите **«Продолжить настройку»** с тем же именем и проверьте план. При ошибке проверьте её текст и текущее состояние панели. Открывайте готовую ссылку из домашней сети с обычной проверкой TLS. Убедитесь, что загрузился XKeen. Покажите владельцу проверенный адрес и QR из блока **«Face ID на iPhone»**. При предупреждении о сертификате оставьте настройку незавершённой до успешной проверки.
5. Владелец подключает iPhone к домашнему Wi-Fi, открывает ссылку в Safari, входит с паролем и одноразовым кодом, выбирает **Настройки → Вход и безопасность → Включить вход по Face ID** и подтверждает сохранение ключа на iPhone. При следующем входе на том же адресе доступна кнопка **«Войти по Face ID»**. Готовый HTTPS и успешный вход по ключу отмечайте отдельно по фактическому результату каждого шага.

Адрес и QR конкретной установки показывайте владельцу в частном канале. Для репозитория, демонстраций и публичных отчётов используйте вымышленные адреса. Пользовательские настройки, снимки панели с реальным доменом, сертификаты, закрытые ключи и данные входа храните вне публикуемых материалов.
